Структура официального сайта

Официальный сайт состоит из следующих страниц:

  • Главная страница — общие сведения об индивидуальном предпринимателе, контакты и ссылки на основные разделы;
  • Сведения об образовательной организации — настоящая страница; содержит 14 подразделов (список приведён выше), в каждом из которых размещена информация в соответствии с его названием;
  • Платные образовательные услуги — стоимость занятий (подраздел раздела «Сведения»);
  • Политика обработки персональных данных — отдельный документ.

Навигация по подразделам доступна на каждой странице раздела. Версия сайта для слабовидящих включается кнопкой в верхней части страницы.

  • Министерство просвещения Российской Федерации (Минпросвещения России) — edu.gov.ru
